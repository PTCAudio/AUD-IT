CL5 setup (one-time)

On the console: SETUP → MIDI/GPI → MIDI

• Set MIDI mode to NRPN

• Set Parameter Change → Rx so the desk accepts incoming changes

• Device number here must match the console's MIDI device/channel setting (default 1 → "10" byte)

Message anatomy: 43 1n 3E 19 01 <element×2> <index×2> <ch×2> <data×5> — Yamaha CL parameter change. Element 01 14 = input patch, 01 1E (index 00 01) = channel color.

Color numbers follow the CL Editor picker order (Blue=0 … Off=8). Blue/Orange are field-confirmed by other CL users; sanity-check the rest against your desk the first time you use them.
